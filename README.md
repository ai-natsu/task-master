# TaskMaster

プロジェクト・タスク・サブタスク（無制限階層）・タグ・優先度・期限を管理できるデスクトップ版タスク管理アプリ。ドラッグ&ドロップによる並び替え、ツリー/カンバン/ガントの3ビュー、統計ダッシュボードを備える。表示言語は日本語／English（設定画面で切替）。単一の `TaskMaster.exe` として配布でき、利用者に Python などのインストールは不要。

## ブランチ構成

- `develop/v1` — Node.js/TypeScript（Express+Prisma+React）版。V2 と仕様をそろえる範囲で更新する。
- `develop/v2` — 現在のリポジトリのデフォルトブランチ。Python+CustomTkinter 版の開発はこちらで行う。

## 配布とデータの保存場所

### 配布方式
- 配布は **zip**。解凍すると `TaskMaster/` フォルダができ、その中の `TaskMaster.exe` をダブルクリックするだけで起動する（インストール不要）。
- zip の中身：`TaskMaster.exe`、利用者向けの `README.txt`（起動方法・データの保存場所・バックアップ方法）、`THIRD_PARTY_NOTICES.txt`（利用ライブラリのライセンス表記）、祝日 CSV の例 `holidays_sample.csv`。
- 対応 OS は **Windows**。Mac 版は近日対応予定。

### データの保存場所
- **データは `TaskMaster.exe` と同じフォルダの `taskmaster.db` に保存されます。**（初回起動時に自動で作成される。配布物には含まれない）
- バックアップや別の PC への移行は、アプリを終了してから `taskmaster.db` をコピーするだけでよい。
- `taskmaster.db` を削除するとデータがすべて消える。アプリを入れ替えるときは、`taskmaster.db` を残したまま `TaskMaster.exe` だけを差し替える。
- Program Files など書き込みできない場所には置かないこと（データを保存できず起動に失敗する）。ドキュメントやデスクトップなど、書き込める場所に置く。

## 機能の概要

詳しい仕様は [基本設計書](docs/BASIC_DESIGN.md) を参照。

### 共通
- サイドバーから ダッシュボード／プロジェクト一覧／設定／各プロジェクトへ移動する（アーカイブ済みのプロジェクトは非表示）。

### ① ダッシュボード
全プロジェクト横断の概要。統計カード（プロジェクト数、直近7日の完了数、タスク総数、完了率、期限超過、期限が近い＝本日〜3日後の4日間）、期限超過／期限が近いタスクの一覧（各最大8件）、プロジェクトカード。

### ② プロジェクト一覧
プロジェクトの作成・編集・アーカイブ／復元・削除。アーカイブしたプロジェクトはサイドバーとダッシュボードから消える（「アーカイブ済みも表示」で確認・復元できる）。

### ③ プロジェクト詳細
- ツリー／カンバン／ガントの3ビュー、キーワード・ステータス・優先度・タグでの絞り込み、統計の表示切替。
- **操作の共通ルール**：ツリーの行・カンバンのカードはクリックで編集、ガントのバーと行名はダブルクリックで編集、ドラッグで移動・並べ替え。詳細は [操作仕様書](docs/OPERATION_SPEC.md)。
- ツリー：無制限の階層。クリックで編集、右クリックでサブタスク追加・編集・ステータス変更・削除。ドラッグで並べ替え・親の付け替え。
- カンバン：ステータスごとの列。カードを別の列へドラッグするとステータス変更、同じ列内なら並べ替え（ドラッグ中はカード全体が追従）。
- ガント：開始日〜期限をステータス色のバーで表示（土日・祝日を色分け、今日に縦線）。バー中央のドラッグで日程を移動、バー端のドラッグで期間を伸縮。行名のドラッグで並べ替え・親の付け替え。
- タスクの作成・編集：タイトル・詳細・ステータス・優先度・開始日・期限・親タスク（循環は拒否）・タグ（その場で新規作成、右クリックで削除）。

### ④ 設定
ステータス（追加・改名・色・並べ替え・削除、「完了として扱う」）、祝日（追加・編集・削除・CSV 一括登録）、タグ（改名・色・削除）、言語（日本語／English）を管理する。

## 起動方法（開発者向け）

配布版（`TaskMaster.exe`）の使い方は「配布とデータの保存場所」を参照。ここでは、ソースから動かす方法を示す。

### 前提

- Python 3.11 以上（Windows。Mac は近日対応予定）
- 画面を開ける環境（ディスプレイ）

### 初回だけ行う準備

リポジトリのルートで実行する。

```bash
python -m venv .venv                 # 任意：仮想環境を作る
.venv\Scripts\activate               # 仮想環境を有効にする（PowerShell / cmd。Git Bash は source .venv/Scripts/activate）
pip install -e .[dev]                # 開発用の依存関係を含めてインストール
python seed.py                       # 任意：サンプルデータを入れる（既存データは全削除される）
```

### 起動する

```bash
python -m app.main
```

初回は、リポジトリ直下に `taskmaster.db`（データベース）を作成する。ステータスが 1 件も無い場合は、未着手／進行中／完了／取下げの 4 件が自動で入る。

### 停止する

ウィンドウを閉じる。

### サンプルデータ（seed）を入れるタイミング

- `python seed.py` は、**手動で、必要なときだけ**実行する。自動では実行されない。
- 既存のプロジェクト・タスク・タグを**全削除**して、サンプルを入れ直す。実際のデータが入っているデータベースでは実行しない。
- 配布版（exe）には含まれない。配布版は、初回起動時に空のデータベースを作る。
- テストは、一時ファイルの専用データベースを使うので、seed は不要で、`taskmaster.db` にも触れない。

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| `ModuleNotFoundError` | `pip install -e .[dev]` を実行したか確認する（仮想環境を有効にしているか） |
| 画面が開かない・文字化けする | Python 3.11 以上か、Windows か確認する |
| サンプルデータを入れ直したい | `python seed.py`（既存データは全削除される） |
| データを初期状態に戻したい | `taskmaster.db` を削除して、再度起動する |

## 使い方

起動するとウィンドウが開く。`python seed.py` を実行済みなら、サンプルのプロジェクト・タスクが入った状態で確認できる。

### 1. プロジェクトを作る・アーカイブする

サイドバーの「📁 プロジェクト一覧」から「+ 新しいプロジェクト」で作成。一覧画面で編集・削除・アーカイブができる。アーカイブしたプロジェクトはサイドバー・ダッシュボードに表示されなくなる（データは残り、「アーカイブ済みも表示」で確認・復元できる）。

### 2. タスクを作る・サブタスクを作る

プロジェクト詳細の「+ 新しいタスク」、またはツリー表示で行を右クリックして「+ サブタスクを追加」。サブタスクにさらにサブタスクを追加でき、階層に制限はない。親を変更したい場合はタスクを編集し、「親タスク」欄で選び直す（自分自身やその子孫には移動できない）。

### 3. タスクを編集する・ステータスを更新する・並び替える

ツリーの行・カンバンのカードを**クリック**、ガントのバーや行名を**ダブルクリック**すると編集画面が開く。ツリー表示では行を右クリックして「ステータス変更」もできる。ドラッグでの並び替えは同じ親を持つタスク同士でのみ有効（異なる親へは編集画面の「親タスク」で移動する）。

### 4. カンバン／ガントで見る・日程を変える

プロジェクト画面上部の切替ボタンで「カンバン」「ガント」に切り替えられる。カンバンはカードを列間・列内でドラッグ。ガントはバーを左右にドラッグすると開始日と期限が一緒に動き、バーの端をドラッグすると期間だけが変わる。

### 5. ステータス・祝日・タグを自分用に変える

サイドバー下部の「⚙️ 設定」から、ステータスの追加・名称/色の変更・並び替え・削除、ガントの土日祝の色分けに使う祝日の登録（個別追加のほか CSV の一括読み込み。列順は「日付, 名称」）、プロジェクトを横断して共有するタグの管理ができる。「完了として扱う」を付けたステータスが、完了率などの集計で「完了」と見なされる。

### 6. 表示言語を切り替える

「⚙️ 設定」の「言語 / Language」で日本語／English を切り替えられる。切替は即座に画面全体へ反映され、選んだ言語は次回起動時も保持される。ステータス名やタグ名などご自身で入力した内容は翻訳されない。

## テスト・ビルド（開発者向け）

```bash
python -m pytest                              # 全テスト（単体・結合・UI 部品・E2E）
python -m pytest -m "not gui and not e2e"     # 速い層だけ（単体・結合。画面を開かない）
python -m pytest tests/gui                    # UI 部品のテスト（入力チェック・確認ダイアログなど）
python -m pytest tests/e2e                    # E2E（画面遷移・モーダル。実際にウィンドウが開く）
python -m ruff check .                        # 静的解析
python packaging/build_exe.py     # packaging/dist/TaskMaster.exe を生成（初回は数分かかる）
python packaging/build_zip.py     # 上記のビルド＋配布用 zip（packaging/dist/TaskMaster-<版>-win64.zip）を作成
```

UI 部品と E2E は、実際にウィンドウを開く（実行中は操作を控える）。画面を開けない環境では、自動でスキップされる。
テストの方針・構成・実行方法は [テスト設計書](docs/TEST_DESIGN.md)、ビルドは [システム設計書](docs/SYSTEM_DESIGN.md) を参照。
