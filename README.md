# TaskMaster

プロジェクト・タスク・サブタスク（無制限階層）・タグ・優先度・期限を管理できるデスクトップ版タスク管理アプリ。ドラッグ&ドロップによる並び替え、ツリー/カンバン/ガントの3ビュー、統計ダッシュボードを備える。表示言語は日本語／英語（設定画面で切替）。単一の `TaskMaster.exe` として配布でき、利用者に Python などのインストールは不要。

**ブランチ構成**

- `develop/v1` — Node.js/TypeScript（Express+Prisma+React）版。V2 と仕様をそろえる範囲で更新する。
- `develop/v2` — 現在のリポジトリのデフォルトブランチ。Python+CustomTkinter 版の開発はこちらで行う。

## 1. 画面説明

詳しい仕様は [基本設計書](docs/BASIC_DESIGN.md) を参照。

### 1.1 共通
- サイドバーから ダッシュボード／プロジェクト一覧／設定／各プロジェクトへ移動する（アーカイブ済みのプロジェクトは非表示）。

### 1.2 ダッシュボード
全プロジェクト横断の概要。統計カード（プロジェクト数、直近7日の完了数、タスク総数、完了率、期限超過、期限が近い（本日〜3日後の4日間））、期限超過／期限が近いタスクの一覧（各最大8件）、プロジェクトカード。

### 1.3 プロジェクト一覧
プロジェクトの作成・編集・アーカイブ／復元・削除。アーカイブしたプロジェクトはサイドバーとダッシュボードから消える（「アーカイブ済みも表示」で確認・復元できる）。

### 1.4 プロジェクト詳細
- ツリー／カンバン／ガントの3ビュー、キーワード・ステータス・優先度・タグでの絞り込み、統計の表示切替。
- **操作の共通ルール**：ツリーの行・カンバンのカードはクリックで編集、ガントのバーと行名はダブルクリックで編集、ドラッグで移動・並べ替え。詳細は [操作仕様書](docs/OPERATION_SPEC.md)。
- ツリー：無制限の階層。クリックで編集、右クリックでサブタスク追加・編集・ステータス変更・削除。ドラッグで並べ替え・親の付け替え。
- カンバン：ステータスごとの列。カードを別の列へドラッグするとステータス変更、同じ列内なら並べ替え（ドラッグ中はカード全体が追従）。
- ガント：開始日〜期限をステータス色のバーで表示（土日・祝日を色分け、今日に縦線）。バー中央のドラッグで日程を移動、バー端のドラッグで期間を伸縮。行名のドラッグで並べ替え・親の付け替え。
- タスクの作成・編集：タイトル・詳細・ステータス・優先度・開始日・期限・親タスク（循環は拒否）・タグ（その場で新規作成、右クリックで削除）。

### 1.5 設定
ステータス（追加・改名・色・並べ替え・削除、「完了として扱う」）、祝日（追加・編集・削除・CSV 一括登録）、タグ（改名・色・削除）、言語（日本語／英語）を管理する。

## 2. 技術要件

### 2.1 使用技術

| 項目 | 採用技術 |
|---|---|
| 言語 | Python 3.11 以上 |
| 画面 | CustomTkinter（Tk）。ツリーは `ttk.Treeview`、ガントチャートは `tk.Canvas` |
| データベース | SQLite（標準ライブラリの `sqlite3`。ファイルは `taskmaster.db`） |
| 主なライブラリ | customtkinter、charset-normalizer（CSV の文字コード判定）、Pillow |
| テスト | pytest（単体・結合・UI 部品・E2E） |
| 静的解析 | ruff |
| 配布 | Nuitka（Python を含む単一の `TaskMaster.exe` を作る） |

### 2.2 動作要件

- Windows（Mac は近日対応予定）
- 画面を開ける環境（ディスプレイ）
- 配布版（`TaskMaster.exe`）は、Python などのインストールが不要。ソースから動かす場合は、Python 3.11 以上が必要（4 章）。

## 3. 配布とデータの保存場所

### 3.1 配布方式
- 配布は **zip**。解凍すると `TaskMaster/` フォルダができ、その中の `TaskMaster.exe` をダブルクリックするだけで起動する（インストール不要）。
- zip の中身：`TaskMaster.exe`、利用者向けの `README.txt`（起動方法・データの保存場所・バックアップ方法）、`THIRD_PARTY_NOTICES.txt`（利用ライブラリのライセンス表記）、祝日 CSV の例 `holidays_sample.csv`。
- 対応 OS は **Windows**。Mac 版は近日対応予定。

### 3.2 データの保存場所
- **データは `TaskMaster.exe` と同じフォルダの `taskmaster.db` に保存されます。**（初回起動時に自動で作成される。配布物には含まれない）
- バックアップや別の PC への移行は、アプリを終了してから `taskmaster.db` をコピーするだけでよい。
- `taskmaster.db` を削除するとデータがすべて消える。アプリを入れ替えるときは、`taskmaster.db` を残したまま `TaskMaster.exe` だけを差し替える。
- Program Files など書き込みできない場所には置かないこと（データを保存できず起動に失敗する）。ドキュメントやデスクトップなど、書き込める場所に置く。

## 4. 始め方（開発者向け）

ソースコードから動かす方法を示す。配布版（`TaskMaster.exe`）を使う場合は、この章は不要（3 章を参照）。

### 4.1 インストール手順

#### 4.1.1 必要なソフト

| ソフト | 内容 | 備考 |
|---|---|---|
| Python 3.11 以上（Windows） | TaskMaster を動かすための実行環境 | **pip（ライブラリの管理ツール）と、画面の部品（Tk）は、Python に同梱される**ので、別にインストールする必要はない |
| Git（任意） | ソースコードの取得に使う | ZIP でダウンロードする場合は不要 |

#### 4.1.2 Python のインストール（Windows）

1. https://www.python.org/downloads/ を開き、「Download Python 3.x」のボタンから、Windows 用のインストーラーをダウンロードする。
2. ダウンロードしたファイルを実行する。最初の画面で、**「Add python.exe to PATH」に必ずチェックを入れて**から、「Install Now」を押す。
3. インストール後、**ターミナルを開き直す**（次の確認コマンドを認識させるため）。

コマンドでインストールする場合（PowerShell。**どのフォルダで実行してもよい**）：

```bash
winget install Python.Python.3.12
```

**インストールの確認**

ターミナルで（**どのフォルダでもよい**）次を実行し、バージョンが表示されればよい（3.11 以上）。

```bash
python --version      # 例：Python 3.12.7
pip --version
```

Mac 版は、近日対応予定。

#### 4.1.3 ソースコードの入手

どちらかの方法で、ソースコードを入手する。

**実行する場所：** ソースコードを置きたいフォルダ（例：`C:\Users\あなたの名前\work`）でターミナルを開いて実行する。実行すると、そのフォルダの中に `task-master` フォルダができる。**この `task-master` フォルダが、以降の「クローンしたリポジトリのルートディレクトリ」である。**

```bash
git clone https://github.com/ai-natsu/task-master.git
cd task-master
git checkout develop/v2
```

または、GitHub のリポジトリのページで、ブランチを `develop/v2` にして「Code」→「Download ZIP」を選び、ダウンロードした ZIP を解凍する。

#### 4.1.4 ターミナルの開き方

以降のコマンドは、**クローンしたリポジトリのルートディレクトリ**（`pyproject.toml` と `README.md` があるフォルダ。ZIP でダウンロードした場合は、解凍したフォルダ）で、ターミナルを開いて実行する。

エクスプローラーでそのフォルダを開き、アドレスバーに `powershell` と入力して Enter を押す。または、フォルダの何もない所を右クリックして「ターミナルで開く」を選ぶ。

#### 4.1.5 ライブラリのインストール（初回だけ）

**実行する場所：** クローンしたリポジトリのルートディレクトリ（4.1.4）。次のコマンドの 1 行目で、そのフォルダに移動する。

```bash
cd <リポジトリのルートフォルダ>
python -m venv .venv                 # 仮想環境（この README の手順専用の、Python のライブラリ置き場）を作る
.venv\Scripts\activate               # 仮想環境を有効にする（PowerShell / コマンドプロンプト）
pip install -e .                     # TaskMaster と、必要なライブラリをインストールする
```

テストやビルドも行う場合は、最後の行を `pip install -e .[dev]` にする（pytest・ruff・Nuitka などの開発用ツールも入る）。

仮想環境を有効にすると、行頭に `(.venv)` と表示される。**新しくターミナルを開いたときは、コマンドを実行する前に、仮想環境を有効にする**（`.venv\Scripts\activate`）。

### 4.2 起動手順

#### 4.2.1 起動する

4.1.5 の準備が済んでいること。以下のコマンドを実行すると、TaskMaster のウィンドウが開く。

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python -m app.main
```

初回は、リポジトリ直下に `taskmaster.db`（データベース）を作成する。

#### 4.2.2 停止する

TaskMaster のウィンドウを閉じる。

#### 4.2.3 初期のデータとサンプルデータ

- **初期のデータベースは空**である（プロジェクト・タスク・タグ・祝日は 0 件）。ステータス（未着手・進行中・完了・取下げ）の 4 件だけが、起動時に自動で入る（ステータスが 1 件も無いときだけ）。
- 配布版（`TaskMaster.exe`）も、初回起動時に同じ状態のデータベースを作る。

サンプルデータを入れたい場合は、以下のコマンドを実行する（既存のデータは全削除される。実際のデータが入っているデータベースでは実行しない）。

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python seed.py
```

- `seed.py` は、**手動で、必要なときだけ**実行する。自動では実行されない。
- テストは、一時ファイルの専用データベースを使うので、seed は不要で、`taskmaster.db` にも触れない。

#### 4.2.4 うまくいかないとき

| 症状 | 対処 |
|---|---|
| Python が見つからない（`python --version` でエラーになる） | Python をインストールする（4.1.2）。**「Add python.exe to PATH」にチェックを入れる**。インストール後は、ターミナルを開き直す |
| `ModuleNotFoundError` | ライブラリが入っていない、または仮想環境が有効でない。4.1.5 の手順で仮想環境を有効にして、`pip install -e .` を実行する |
| ウィンドウが開かない・文字が化ける | Python 3.11 以上か、Windows か確認する。リモート接続など、画面を表示できない環境では動かない |
| データを初期状態に戻したい | TaskMaster を終了してから、エクスプローラーで、リポジトリ直下（配布版は `TaskMaster.exe` と同じフォルダ）の `taskmaster.db` を削除する。次に起動すると、空のデータベースが作られる |
| サンプルデータを入れたい | 4.2.3 のコマンドを実行する（既存のデータは全削除される） |

## 5. 使い方

起動するとウィンドウが開く。初期のデータベースは空なので、最初にプロジェクトを作る。サンプルデータを入れた場合（4.2.3）は、サンプルのプロジェクト・タスクが入った状態で確認できる。

### 5.1 プロジェクトを作る

サイドバーの「📁 プロジェクト一覧」から「+ 新しいプロジェクト」で作成。一覧画面で編集・削除ができる。

### 5.2 タスクを作る

プロジェクト詳細画面の「+ 新しいタスク」をクリックし、タイトル（必須）、詳細、ステータス、優先度、開始日、期限、タグを入力して「作成」。タグは既存のものを選ぶか、入力欄に新しいタグ名を入れて「追加」するとその場で作成できる。

### 5.3 サブタスクを作る

ツリー表示で、タスクの行を右クリックして「+ サブタスクを追加」を選ぶ。サブタスクにさらにサブタスクを追加でき、階層に制限はない。

親を変更したい場合は、タスクを編集し、「親タスク」欄で選び直す（自分自身やその子孫には移動できない）。

### 5.4 タスクを編集する・ステータスを更新する

ツリーの行・カンバンのカードを**クリック**、ガントのバーや行名を**ダブルクリック**すると編集画面が開く。ツリー表示では行を右クリックして「ステータス変更」もできる。

### 5.5 並び替える

ツリーの行・ガントの行名をドラッグすると、並び順を変えられる。行の上端・下端へドロップすると兄弟として挿入され、中央へドロップすると子になる（自分自身の配下には移動できない）。カンバンは、カードを列間・列内でドラッグする。

### 5.6 カンバン／ガントで見る・日程を変える

プロジェクト画面上部の切替ボタンで「カンバン」「ガント」に切り替えられる。カンバンはカードを列間・列内でドラッグ。ガントはバーを左右にドラッグすると開始日と期限が一緒に動き、バーの端をドラッグすると期間だけが変わる。

### 5.7 プロジェクトをアーカイブする

プロジェクト一覧画面で、プロジェクトのアーカイブができる。アーカイブしたプロジェクトはサイドバー・ダッシュボードに表示されなくなる（データは残り、「アーカイブ済みも表示」で確認・復元できる）。確認ダイアログで「アーカイブする」を押すと実行される。

### 5.8 ステータス・祝日・タグを自分用に変える

サイドバー下部の「⚙️ 設定」から、ステータスの追加・名称/色の変更・並び替え・削除、ガントの土日祝の色分けに使う祝日の登録（個別追加のほか CSV の一括読み込み。列順は「日付, 名称」）、プロジェクトを横断して共有するタグの管理ができる。「完了として扱う」を付けたステータスが、完了率などの集計で「完了」と見なされる。

### 5.9 表示言語を切り替える

「⚙️ 設定」の「言語 / Language」で日本語／英語を切り替えられる。切替は即座に画面全体へ反映され、選んだ言語は次回起動時も保持される。ステータス名やタグ名などご自身で入力した内容は翻訳されない。

### 5.10 検索・絞り込み

プロジェクト詳細画面のフィルタバーで、キーワード検索・ステータス・優先度・タグを組み合わせて絞り込める。「クリア」ですべてリセットされる。

### 5.11 統計を見る

- プロジェクト詳細画面の「統計を表示」で、そのプロジェクトに絞った完了率・期限超過件数などを表示する。
- サイドバーの「ダッシュボード」では、全プロジェクト横断の統計と、期限超過／期限が近いタスクの一覧を確認できる。

## 6. テスト手順

テストは、**単体・結合**、**UI 部品**、**E2E** の 3 つに分かれていて、それぞれ別のコマンドで実行する。実行する前に、開発用のツール（pytest など）をインストールしておく（`pip install -e .[dev]`、4.1.5）。

**実行する場所：** この章のコマンドは、**クローンしたリポジトリのルートディレクトリ**（4.1.4）で、**仮想環境を有効にした状態**で実行する。各コマンドの前に、そのフォルダへ移動するコマンドと、仮想環境を有効にするコマンドを書いている。

詳細（種類・置き場所・方針・入力値の上限）は、[テスト設計書](docs/TEST_DESIGN.md) を参照。

### 6.1 単体・結合テスト

画面を開かない、速いテスト。純粋関数（ツリー・ドラッグ判定・ガント・期限判定・多言語・エラー文言）の単体テストと、データ層（SQLite）の結合テストを検証する。

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python -m pytest -m "not gui and not e2e"
```

| やりたいこと | コマンド（ルートディレクトリで、仮想環境を有効にして実行する） |
|---|---|
| 1 ファイルだけ実行する | `python -m pytest tests/integration/test_tasks_db.py` |
| テスト名の一部で絞り込む | `python -m pytest -k "cycle"` |
| 詳しい表示で実行する | `python -m pytest -v` |
| 最初の失敗で止める | `python -m pytest -x` |

結合テストは、テストごとに一時ファイルのデータベースを作り、開発用の `taskmaster.db` には触れない。

### 6.2 UI 部品のテスト

画面の部品（入力欄の文字数の上限、フォームの必須の赤字、確認ダイアログなど）を、実際の Tk のウィジェットで検証する。

1. 実行中は、**ウィンドウが一瞬表示される**。マウス・キーボードの操作を控える。
2. 次のコマンドを実行する。

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python -m pytest tests/gui
```

画面を開けない環境（ディスプレイが無い環境など）では、自動でスキップされる。

### 6.3 E2E テスト

アプリ全体（`AppWindow`）を実際に動かして、画面遷移・モーダル・確認ダイアログを検証する（設計書の画面遷移表に対応）。

1. 実行中は、**ウィンドウが表示される**。マウス・キーボードの操作を控える。
2. 次のコマンドを実行する。

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python -m pytest tests/e2e
```

| やりたいこと | コマンド（ルートディレクトリで、仮想環境を有効にして実行する） |
|---|---|
| 全部（単体・結合・UI 部品・E2E）を実行する | `python -m pytest` |
| テスト名の一部で絞り込む | `python -m pytest tests/e2e -k "archive"` |

E2E は、一時ファイルのデータベースを使い、`taskmaster.db` には触れない。

### 6.4 静的解析（ruff）

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python -m ruff check .
```

エラーが 0 件であること。自動で直せるものは、`python -m ruff check --fix .` で直す。

## 7. ビルド手順

配布用の `TaskMaster.exe` と、配布用の zip を作る。

**実行する場所：** クローンしたリポジトリのルートディレクトリ（4.1.4）で、仮想環境を有効にして実行する。開発用のツール（Nuitka）が必要なので、`pip install -e .[dev]`（4.1.5）が済んでいること。

### 7.1 exe を作る

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python packaging/build_exe.py
```

- 出力：`packaging/dist/TaskMaster.exe`（Git には含まれない）。
- 初回は、C コンパイラ（zig）を自動でダウンロードするため、数分かかる。

### 7.2 配布用の zip を作る

```bash
cd <リポジトリのルートフォルダ>
.venv\Scripts\activate
python packaging/build_zip.py
```

- exe のビルドと、同梱物（利用者向け `README.txt`、`THIRD_PARTY_NOTICES.txt`、祝日 CSV の例）の整理を行い、zip を作る。
- 出力：`packaging/dist/TaskMaster-<版>-win64.zip`。解凍すると `TaskMaster/` フォルダができる。
- ビルド済みの exe を使い、zip だけ作り直す場合は、`python packaging/build_zip.py --skip-build`。

詳細は、[システム設計書](docs/SYSTEM_DESIGN.md) を参照。

## 8. ディレクトリ構成

```
/（クローンしたリポジトリのルートディレクトリ）
├─ app/                  # アプリ本体
│  ├─ main.py            # エントリポイント
│  ├─ constants.py       # 区分値（優先度）、入力欄の文字数の上限
│  ├─ models.py          # データクラス
│  ├─ i18n.py / locales/ # 多言語（日本語／英語）
│  ├─ db/                # SQLite を直接扱うデータ層（schema.sql を含む）
│  ├─ logic/             # ツリー構築・ドラッグ判定・ガント計算・期限判定（純粋関数）
│  ├─ ui/                # CustomTkinter の画面・部品
│  └─ assets/            # アイコン
├─ tests/
│  ├─ unit/              # 単体テスト
│  ├─ integration/       # 結合テスト（データ層 + SQLite）
│  ├─ gui/               # UI 部品のテスト
│  └─ e2e/               # 画面遷移の E2E
├─ packaging/            # exe・配布 zip の作成（build_exe.py / build_zip.py など）
├─ docs/                 # 設計書
├─ seed.py               # サンプルデータの投入（既存データを全削除する）
└─ pyproject.toml        # プロジェクト設定（依存ライブラリ、ruff、pytest）
```

データベース（`taskmaster.db`）、仮想環境（`.venv/`）、ビルドの出力（`packaging/dist/`）は Git に含めない。
