# TaskMaster

プロジェクト・タスク・サブタスク（無制限階層）・タグ・優先度・期限を管理できるデスクトップ版タスク管理アプリ。ドラッグ&ドロップによる並び替え、ツリー/カンバン/ガントの3ビュー、統計ダッシュボードを備える。表示言語は日本語／英語（設定画面で切替）。単一の `TaskMaster.exe` として配布でき、利用者に Python などのインストールは不要。

## ブランチ構成

- `develop/v1` — Node.js/TypeScript（Express+Prisma+React）版。V2 と仕様をそろえる範囲で更新する。
- `develop/v2` — 現在のリポジトリのデフォルトブランチ。Python+CustomTkinter 版の開発はこちらで行う
