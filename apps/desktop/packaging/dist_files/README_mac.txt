TaskMaster {version}（Mac 版）
==============================

プロジェクト・タスク・サブタスクを管理するデスクトップアプリです。
Python などのインストールは不要です。


1. 起動のしかた
---------------
1. zip を解凍すると「TaskMaster」フォルダができます。
2. フォルダの中の「TaskMaster.app」を、「アプリケーション」フォルダなど、好きな場所に移します。
3. 「TaskMaster.app」をダブルクリックします。

初回だけ、「開発元を検証できないため開けません」と表示されることがあります。
その場合は、次のどちらかで開いてください。
  ・「TaskMaster.app」を右クリック（Control を押しながらクリック）→「開く」→ 確認画面で「開く」
  ・「システム設定」→「プライバシーとセキュリティ」→ 下の方の「このまま開く」


2. データの保存場所（バックアップ）
-----------------------------------
データは、次のファイルに保存されます。

  ~/Library/Application Support/TaskMaster/taskmaster.db
  （Finder で「移動」→「フォルダへ移動…」に、上のパスを入力すると開けます）

・バックアップや別の Mac への移行は、アプリを終了してから、このファイルをコピーするだけです。
・このファイルを削除すると、データがすべて消えます。
・バージョンアップは、「TaskMaster.app」を差し替えるだけです（データは別の場所なので、消えません）。


3. 同梱のファイル
-----------------
TaskMaster.app           アプリ本体
README.txt               この文書
LICENSE.txt              TaskMaster のライセンス（AGPL-3.0）
THIRD_PARTY_NOTICES.txt  利用しているライブラリのライセンス表記
holidays_sample.csv      祝日の取り込み例（2026 年分）

祝日の取り込み：アプリの「設定」→「祝日」→「CSVから読み込む」で、
holidays_sample.csv を選びます。列の順は「日付, 名称」です。
同じ日付がすでにあると、名称が上書きされます。
※ holidays_sample.csv は例です。実際の暦は公式の情報で確認してください。


4. 操作のメモ
-------------
・右クリックのメニューは、マウスの副ボタン、または Control を押しながらクリックで開きます。
・表示言語は、「設定」→「言語 / Language」で、日本語／英語を切り替えられます。
