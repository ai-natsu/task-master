TaskMaster {version}（Windows 版）
==================================

プロジェクト・タスク・サブタスクを管理するタスク管理アプリです。
インストールは不要です。この TaskMaster フォルダの中の TaskMaster.exe を
ダブルクリックすると起動します。


1. はじめかた
-------------
1) zip を解凍すると「TaskMaster」フォルダができます。
2) フォルダの中の TaskMaster.exe をダブルクリックします。
   （初回は準備のため、起動まで数秒かかることがあります）
3) 左の「プロジェクト一覧」から「+ 新しいプロジェクト」を作り、
   「+ 新しいタスク」でタスクを追加します。

使い方の詳細は、アプリ内の画面と配布元の README を参照してください。


2. データの保存場所（重要）
---------------------------
データは、TaskMaster.exe と同じフォルダの「taskmaster.db」に保存されます。
初回の起動時に自動で作られます（この zip には入っていません）。

・バックアップ／別の PC への引っ越し
  アプリを終了してから、taskmaster.db をコピーしてください。
・アプリのバージョンアップ
  taskmaster.db は残したまま、TaskMaster.exe だけを新しいものに差し替えます。
・taskmaster.db を削除すると、登録したデータはすべて消えます。
・Program Files など、書き込みできない場所には置かないでください
  （データを保存できず、起動に失敗します）。
  デスクトップやドキュメントなど、書き込めるフォルダに置いてください。


3. 同梱のファイル
-----------------
TaskMaster.exe           アプリ本体
README.txt               この文書
THIRD_PARTY_NOTICES.txt  利用しているライブラリのライセンス表記
holidays_sample.csv      祝日の取り込み例（2026 年分）

祝日の取り込み：アプリの「設定」→「祝日」→「CSVから読み込む」で、
holidays_sample.csv を選びます。列の順は「日付, 名称」です。
同じ日付がすでにあると、名称が上書きされます。
※ holidays_sample.csv は例です。実際の暦は公式の情報で確認してください。


4. 起動時の注意
---------------
・Windows の「SmartScreen」や、ウイルス対策ソフトが警告を出すことがあります。
  このアプリは署名されていないためです。配布元が信頼できる場合は、
  警告の「詳細情報」→「実行」で起動できます。
・対応 OS は Windows です。Mac 版は近日対応予定です。
