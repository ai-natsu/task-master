# 操作仕様書 — クリック・ドラッグ・マウスオーバー

TaskMaster V1（Web 版）と V2（デスクトップ版）で、画面上のマウス操作をそろえるための仕様。同じ内容を V1・V2 の両方の `docs/OPERATION_SPEC.md` に置く。表の「V1」「V2」は、それぞれの現在の動作を示す。

## 方針

- 編集を開く操作は、ドラッグと競合しない場所ではシングルクリック（ツリーの行・カンバンのカード）、ドラッグで日程を動かすガントのバーと、並べ替えに使うガントの行名はダブルクリックとする。ガントでシングルクリックにしないのは、ドラッグ開始との誤操作を避けるため。
- クリックとドラッグは、動いた距離で分ける（5px 以下の動きはクリック、それを超えたらドラッグ）。ドラッグした場合は、離した直後でも編集は開かない。ツリーのドラッグ開始は、V1 はドラッグハンドル、V2 は行そのもの。
- 「何もしない」と書いた操作は、編集を開かず、データも変えない（ツリーのダブルクリックによる展開/折りたたみの切替も行わない）。
- 見た目の部品の違い（ブラウザの標準部品とデスクトップの標準部品）による差は、表の V1 / V2 欄に併記する。

## 操作の一覧

| 場所 | 操作 | V1 | V2 |
|---|---|---|---|
| ツリーの行 | シングルクリック | 編集画面を開く（行内のボタン・セレクト上のクリックは、それぞれの操作を優先） | 編集画面を開く（展開/折りたたみの矢印上のクリックは除く） |
| ツリーの行 | ダブルクリック | 何もしない | 何もしない |
| ツリーの行 | 編集の補助手段 | 行末の「編集」ボタン | 右クリックメニューの「編集」 |
| ツリーの行 | ステータス変更・サブタスク追加・削除 | 行内のセレクトと、行末の「+サブ」「削除」ボタン | 右クリックメニュー（サブタスクを追加・編集・ステータス変更・削除） |
| ツリーの行 | ドラッグ | ドラッグハンドルで並べ替えと親の付け替え（ガントの行名と同じ規則）。ドロップ位置を線または枠で表示 | 行をドラッグして並べ替えと親の付け替え（ガントの行名と同じ規則）。ドロップ位置を線または色で表示 |
| ツリーの行 | マウスオーバー | 行を薄く強調。ドラッグハンドルと行末のボタンが現れる | 行を薄く強調 |
| カンバンのカード | シングルクリック | 編集画面を開く | 編集画面を開く |
| カンバンのカード | ダブルクリック | 何もしない | 何もしない |
| カンバンのカード | ドラッグ | 列間・列内の移動。カード全体がカーソルに追従 | 列間・列内の移動。カード全体がカーソルに追従 |
| カンバンのカード | マウスオーバー | 枠をアクセント色で強調。カーソルは「つかむ」形 | 枠をアクセント色で強調。カーソルは「つかむ」形 |
| ガントのバー | シングルクリック | 何もしない | 何もしない |
| ガントのバー | ダブルクリック | 編集画面を開く | 編集画面を開く |
| ガントのバー | ドラッグ | 中央で開始日・期限を平行移動、端で期間を伸縮 | 中央で開始日・期限を平行移動、端で期間を伸縮 |
| ガントのバー | マウスオーバー | バーを少し薄く表示。カーソルは中央=移動、両端=左右矢印。ツールチップに名称と期間 | バーを少し薄く表示。カーソルは中央=移動、両端=左右矢印。ツールチップに名称と期間 |
| ガントの行名 | シングルクリック | 何もしない | 何もしない |
| ガントの行名 | ダブルクリック | 編集画面を開く | 編集画面を開く |
| ガントの行名 | ドラッグ | 並べ替えと親の付け替え。行の上端 25% = 直前に兄弟として挿入、下端 25% = 直後に兄弟として挿入、中央 = その行の子にする（最上位への移動も可）。自分自身や自分の配下には移動できない。ドロップ位置を線または枠で表示 | 同じ |
| ガントの行名 | マウスオーバー | 行全体を薄く強調し、行名の文字色を強調。ツールチップに名称と「ダブルクリックで編集」 | 同じ |
| サイドバーのプロジェクト | シングルクリック | そのプロジェクトの画面へ移動 | そのプロジェクトの画面へ移動 |
| サイドバーのプロジェクト | マウスオーバー | 背景を強調（編集・削除のボタンはない。「プロジェクト一覧」画面で行う） | 背景を強調（編集・削除のボタンはない。「プロジェクト一覧」画面で行う） |

## 補足

- 右クリックメニューは V2 のみ。V1 でも実現できる（ブラウザ標準のメニューを止めて独自のメニューを出す）が、現状は行末のボタンで代替している。
- ガントの行名のドラッグ判定（`plan_row_drop` / `planRowDrop`）は純粋関数として切り出し、V1・V2 とも単体テストで検証している。
